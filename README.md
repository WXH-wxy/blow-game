# 🌬️ 大风起兮 — 吹气小游戏原型

对手机麦克风吹气 → 风力 → 把东西吹上天。零依赖：原生 Canvas + Web Audio API。

> **✨ v2 视觉美化版**：毛玻璃 UI、渐变设计系统、更生动的场景绘制、通关彩带等，详见文末「视觉美化」。

- **热身关 1「晨风村」**：吹飞树叶 / 草帽 / 雨伞
- **热身关 2「守树人」**：把抱着树的人吹飞（风力持续够猛才会脱手，脱手了还可能再抱住）
- **场景1「海滨城市」**：海边大街，把抱着电线杆的美女吹上天（风越大裙摆扬得越高、长发飘动，抓力耗尽才会脱手）
- 场景2 / 场景3：制作中，敬请期待

## 怎么运行

**手机直接玩（线上）**：https://wxh-wxy.github.io/blow-game/

**电脑**：直接双击 `index.html`（Chrome/Edge 中 `file://` 也可用麦克风），或点「演示模式」用鼠标/空格吹。

**手机**：浏览器调麦克风必须 HTTPS。任选：
- 传到 GitHub Pages / Netlify Drop / Vercel 等静态托管，拿到 https 链接
- 或本机起服务后用 ngrok / cloudflared 生成 https 临时链接
- iPhone 麦克风在底部，对着底部吹

首次进入会校准（安静 1 秒 → 用力吹 1.6 秒），中途可点 HUD 的「校准」重来。

## 调试参数

- `index.html?autowind=1`：自动循环风力（4 秒一个周期：满风 2.4s → 停 1.2s → 恢复），用于自动化/物理测试，无需任何输入
- 右上角 🐛 或按 `D`：调试面板（rms / 高频占比 / 风力 / 校准值）

## 调参

手感参数集中在 `game.js` 顶部 `TUNE` 区块，中文注释。核心项：

| 参数 | 作用 | 调大效果 |
|------|------|----------|
| `WIND_ACC` | 基础风加速度 | 东西更容易吹飞 |
| `SPEECH_LO/HI` | 说话抑制区间（差分RMS/原始RMS） | 更严格区分说话/吹气 |
| `GAMMA` | 低风区增益（<1 小吹更灵敏） | 小吹气反馈更强 |
| `HOLD_DRAIN` | 抓力消耗速度 | 抱树的人更快脱手 |
| `CAL_QUIET/BLOW` | 校准时长 | 更长的适应时间 |

## 已知事项

- 吹气检测用「时间域差分 RMS + 柔性说话抑制」，对大多数手机麦克风都有效；麦克风模式下 HUD 会显示 🎤 拾音电平表，吹气时电平条应明显跳动
- 若说话会误触发，把 `SPEECH_LO` 调大；若吹气完全没反应，点 🐛 看 `dR` 值——吹气时 dR 应接近 1（白噪声），若 dR 很低说明手机麦克风低频太强，把 `SPEECH_LO` 调小
- 不同手机麦克风灵敏度差异大，靠校准流程归一化；校准失败会回退默认值

## ✨ 视觉美化（v2）

纯视觉升级，**不改任何玩法与手感**，替换 `index.html` / `style.css` / `game.js` 即可。

**UI（style.css + index.html）**
- 设计系统化：CSS 变量统一配色 / 圆角 / 阴影，深空蓝渐变底色
- 首页：渐变色大标题、漂浮装饰动画（🍃💨🌾…）、毛玻璃模式切换胶囊
- 选关卡片：玻璃质感 + 图标徽章 + 依次入场动画
- 按钮：胶囊形渐变 + 光泽扫过 + 按压反馈；风力条流光渐变 + 大风热浪动画
- HUD / Toast / 校准条 / 通关统计全部毛玻璃化，通关撒 emoji 彩带雨
- 支持 `prefers-reduced-motion`（系统开启「减少动效」时自动关闭动画）

**场景（game.js 绘制层）**
- 村庄：多段渐变天空、太阳光晕、双层远山 + 雾气、渐变草地、随风弯折的草、小花点缀
- 云：蓬松多弧拼合 + 体积阴影 + 高光；树：渐变树干 + 树根 + 立体多层树冠
- 海滨：黄昏感天空、更大太阳光晕、海面阳光倒影（随风增强）、远帆船驶过
- 环境落叶颜色更丰富
